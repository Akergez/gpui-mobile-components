InputMode × WidthClass

Six combinations, three of which are common. A narrow desktop window gets one pane but keeps hover and dropdowns. A tablet or an unfolded phone gets two panes but keeps ripples and sheets. The width class is measured in rems, so zooming the interface on a desktop moves it the same way narrowing the window does.

API

pub enum InputMode { Pointer, Touch }
pub enum WidthClass { Compact, Medium, Expanded }

/// What this frame is drawn for. Read in render; never cached.
pub struct Form { input: InputMode, width: WidthClass }
impl Form {
    pub fn of(window: &Window, cx: &App) -> Self;   // width = viewport / rem_size
    pub fn input(&self) -> InputMode;
    pub fn width(&self) -> WidthClass;
    pub fn is_touch(&self) -> bool;
}

/// Once, after gpui_kit::init and gpui_adaptive_colors::init.
pub fn init(input: InputMode, cx: &mut App);
