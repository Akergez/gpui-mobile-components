Density, shape, type and motion

Both skins take every length from the gpui-kit rem, which is the theme's font_size and therefore the zoom. Each skin applies its own scale on top of the rem. Shape, type and motion scales that the gpui-kit theme cannot store live in the design system's own Global. The Coding Guides warn that apply_semantic_tokens does not keep custom spacing or elevation scales.

pub struct Scale { radius: Radii, type_: TypeScale, motion: Motion, density: Density }
impl Scale {
    pub fn pointer() -> Self;   // from gpui-kit's own semantic tokens
    pub fn touch() -> Self;     // M3 values in rems at 16 px = 1 rem
}
impl Global for Scale {}           // set by adaptive::init(input)

Motion runs on the window's frame clock (with_animation, or a Motion stepped per frame the way money-manager's bottom_sheet.rs does it), so what a sheet holds keeps its state while the sheet moves.
