The glue

The design system depends on gpui-kit, gpui-adaptive-colors and gpui-android-glue (0.4). Every glue function exists on every platform and does the desktop's thing, or nothing, off Android. Intents therefore call it unconditionally, and feature code never touches it.

GlueUsed byHow
launch::run(app, Config, Assets, start)app-androidThe entry point calls adaptive::init(InputMode::Touch, cx) inside start. The desktop's main passes Pointer and calls gpui_android_glue::init itself.
back::push(handler) → GuardNavigator, Sheet, Panel, Lookup, selection modeEach layer that back should close holds a Guard while it is open: a pushed page, an open sheet, an overlay panel, a selection. Dropping the guard removes the layer.
guard.gesture() + back::preview(page, gesture).under(..).swipe_back(..)Navigator (Touch)Predictive back. The page under the top one is built only while a gesture is in progress. swipe_back is on for pages without a sideways scroller, which the intent knows because it owns the page's scroll areas.
back::open_dialogConfirm, Ask, Form (Pointer on Android tablets)Used in place of window.open_dialog, so the back gesture closes the dialog.
insets::system_bars()Screen, Destinations, SheetTop inset pads the app bar. Bottom inset pads the navigation bar, or the sheet when there is no navigation bar.
keyboard::keyboard_inset(window), is_upForm, Composer, Lookup, Sheet, Screen (FAB)Whatever is typed into pads by bars.max(keyboard). The navigation bar keeps only the bars' inset and goes under the keyboard. The FAB rides above the keyboard.
keyboard::follow(id, event, Purpose), on_tapTextField, Amount, Composer, LookupThe intent's purpose (text, number, email, search, password) sets the keyboard type and its action key: Next, Done, Search, Send.
chrome::title_frame(content, Frame)Screen (root)The window's title bar on a desktop, a plain strip under the status bar on a phone.
appearance::{system_mode, change_to}Appearance settings (shared screen)Light or dark plus status bar icons. The colours stay gpui-adaptive-colors.
clipboard, edit_menuFeed, Review, ItemActions"Copy text" in the long-press sheet calls clipboard::push. A long press inside text gets the system toolbar from init.
documents::save, path pickerCommand "Export…", Form file fieldThe system save dialog or document picker on Android, a file dialog on a desktop.
open_urlFeed links, settingsOpens links in the system browser.

What the glue lacks and the design system should ask it for

  • Haptics: a light tick on long press, on swipe-action threshold and on a sheet's detent. Proposed as gpui_android_glue::haptics::tick(), a no-op on a desktop.
  • Resume hook: one place to call gpui_adaptive_colors::refresh(cx) when the app comes to the front, since Android does not announce a wallpaper colour change.
  • Share sheet: share::text/file for "Share…" commands (matterfast permalinks, money-manager CSV).
