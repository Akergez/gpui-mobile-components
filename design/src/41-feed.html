Feed: a conversation

A bottom-anchored, virtualised list of entries that only lays out what is visible, with day separators, a "new messages" line, author grouping and paging upwards. Entries are domain-specific but built from shared parts: Message (avatar, author, time, rich text, attachments, reactions, thread footer), Bubble for your own turn in an agent chat, and AgentRun (collapsible thinking, tool calls, plan, permission Ask). Hover actions and long press come from ItemActions.

matterfast: chat/feed/*, message/view/*aiddiction: chat.rs (runs, tools, plan, permissions, sign-in)
Feed::new(&self.feed)                 // FeedState: bottom-anchored list, paging up, unread line, keyed by post id
    .entry(|entry, window, cx| match entry {
        Entry::Post(post) => Message::new(post.id).author(..).time(..).body(Markdown::new(..))
                                .attachments(..).reactions(..).thread(..).into_any_element(),
        Entry::Run(run)   => AgentRun::new(run.id).thinking(..).tools(..).ask(..).into_any_element(),
        Entry::Day(day)   => DaySeparator::new(day).into_any_element(),
    })
    .item_actions(post_actions)
  • The feed is the one vertical scroller of its page. Code blocks and wide tables inside a message scroll sideways with lock_scroll_axis, so a swipe over them does not move the feed, and pages with them keep swipe-back on only where the gesture starts outside them.
  • Rich text is gpui-kit TextView (Markdown). On Touch a long press is taken by ItemActions before text selection, and "Copy text" lives in the sheet.
  • Reactions: tap toggles your own, long press lists who reacted (matterfast reaction_tooltip.rs is a tooltip on Pointer).
